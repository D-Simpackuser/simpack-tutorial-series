## English

The complete existing upload workflow is retained in [maintainer publishing](maintainer/publishing.md). Its rights, authorization, target-project, private-visibility and exact-asset checks remain relevant to authorized media work. It records the original local preparation and Release workflow, not permission to repeat an upload.

For the current documentation workflow, use [maintainer architecture](maintainer/architecture.md): local build and validation are separate from GitHub changes. Existing videos, subtitles, tags and Release attachments remain unchanged. The read-only verifier does not authorize an upload, Release edit or visibility change. Reader download instructions are in [using the library](using-the-library.md).

## 简体中文

原有完整上传流程保留在[维护者发布说明](maintainer/publishing.md)。素材权利、本轮授权、目标工程、private 可见性及精确附件检查仍用于已获准的媒体操作。该文记录原本地准备与 Release 流程，不授权重复上传。

当前文档维护流程见[维护架构说明](maintainer/architecture.md)：本地构建、校验与 GitHub 修改分离。既有视频、字幕、tag 和 Release 附件保持不变；只读核验不授权上传、Release 编辑或可见性变更。读者下载方式见[下载与使用](using-the-library.md)。
