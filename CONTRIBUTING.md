# Contributing / 贡献说明

[English](#english) · [简体中文](#简体中文) · [Project](README.md) · [项目首页](README.zh-CN.md)

## English

Corrections to subtitle wording, translated titles, terminology and links are welcome. Use the issue form that fits the problem: subtitle/title correction, broken link or course question. Describe one concrete problem and include the series ID and stable lesson ID, such as `6` and `s06-e001`. For a subtitle issue, include its language, SRT/VTT format and timestamp when relevant. A proposed correction and a short source explanation make the report easier to assess.

Keep the original Chinese title available for identification. A number at the beginning of a filename is not a unique lesson identifier: several distinct courses share prefixes, and titles can recur across series. For a link issue, give the repository page or Release URL and the observed result; redact temporary download signatures and personal details. The repository is public; creating an issue or pull request still requires GitHub sign-in. Report a failing public link with its observed status rather than assuming an attachment is missing.

For a pull request, explain the affected IDs, proposed wording and supporting material. Run the applicable local checks and report what actually ran. The original lesson IDs, file mapping, lesson-page paths and verified media links must stay stable. Documentation-language additions do not authorize adding or renaming subtitle files. Existing subtitle bytes and Release attachments are preserved during this documentation update; a later media or subtitle-content revision needs its own reviewed scope and permission.

Do not submit recordings, model files, screenshots or subtitle text that you have no right to distribute. Do not include passwords, tokens, licence keys, personal paths or private audit records in issues or pull requests. If a security or privacy report needs sensitive evidence, describe its type and affected location without posting the evidence itself. See [sources and rights](PROVENANCE.md) and [quality and versions](docs/quality-and-versions.md).

## 简体中文

欢迎提交字幕措辞、显示题名、术语和链接纠错。请选择对应的问题表单：字幕/译名纠错、链接问题或课程问题。一次描述一个具体问题，并提供系列 ID 与稳定课程 ID，例如 `6` 和 `s06-e001`。字幕问题应说明语言、SRT/VTT 格式，并在相关时提供时间戳。建议改法和简短出处有助于核实。

保留中文原题以便识别。文件名开头数字不能唯一识别课程：不同课目可能有相同前缀，跨系列也可能同名。链接问题请提供仓库页面或 Release 地址、实际访问结果；不要贴临时签名下载地址和个人信息。本仓库已为 public；提交问题或 PR 仍需登录 GitHub。公开链接失败时请记录实际状态，不据此直接认定附件缺失。

PR 应说明涉及的课程 ID、拟改文字及依据，执行相关本地检查，并如实记录已执行范围。原课程 ID、文件映射、详情页路径和已验证媒体链接必须保持稳定。新增文档语言不授权新增或改名字幕文件。本轮文档整理保留既有字幕字节与 Release 附件；后续媒体或字幕正文修订需另行确定范围和权利。

不要提交无权传播的视频、模型文件、截图或字幕文本。问题单和 PR 不应包含密码、token、许可证密钥、个人绝对路径或私有审计记录。涉及安全或隐私时，先说明问题类型与位置，不公开敏感证据本身。参见[来源与权利](PROVENANCE.md)及[质量与版本说明](docs/quality-and-versions.md)。
