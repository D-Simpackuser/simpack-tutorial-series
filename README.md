# Simpack 系列教程目录

本地实际清单：194 个视频、772 个字幕文件，193 课具备四种字幕文件。

仅整理原始文件名、大小和字幕对应关系。系列名称为默认名称，未核实课程作者或资料来源。本轮已确认 194 课的视频上传许可、193 课的中文字幕上传许可和 193 课的英文字幕上传许可；未确认资料仍排除，逐字稿及其他资料不自动放行。
排序是文件名自然排序，不表示已核验教学先后顺序。字幕基础格式检查不代表语义、翻译质量或音画时间轴已校对。

## 下载与使用

视频下载链接已验证：194/194。视频作为每系列的 GitHub Release 附件；使用时下载视频及同课字幕，在本地播放器中选择字幕。
本地字幕副本见[字幕目录](subtitles/README.md)，短英文附件名与稳定课程 ID 对应。缺字幕视频仍保留独立课程，详情页逐项标明缺失。

视频不进入 Git，不使用 Git LFS；第一版未提供在线播放器。
